# FeesCoach

**FeesCoach** is a responsive, browser-based subscription and expense tracker developed as part of my frontend development internship.

## About the Project

The application is designed to help users manage recurring subscriptions and avoid subscription fatigue. It allows users to track subscription costs, renewal dates, free trials, and monthly spending in one place.

## Current Features

* Track recurring subscriptions
* Add, edit, pause, resume, and delete subscriptions
* Categorize subscriptions
* Monitor monthly recurring expenses
* Set a monthly spending budget
* Identify upcoming renewals
* Receive free-trial and budget alerts
* Visualize spending by category
* Store data using browser LocalStorage
* Responsive design for mobile, tablet, and desktop

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* LocalStorage
* Git & GitHub

## Privacy

FeesCoach does not require bank account or payment information. Subscription data is stored locally in the user's browser using LocalStorage.
